# Участие в разработке

Спасибо, что хотите помочь VibeMemory.

## Что принимаем

- **Исправления ошибок** — охотно, лучше с тестом, который без исправления падает.
- **Новые возможности** — сначала issue с описанием: так не уйдёт неделя на то, что не совпадёт с планом ([docs/roadmap.md](docs/roadmap.md)).
- **Документация и спеки** — всегда.

## Как устроен код

- `crates/vibememory-core` — чистая логика без ввода-вывода: имена, слияние, память. Ввод-вывод здесь запрещён линтером.
- `crates/vibememory-cli` — бинарь `vibememory`: хуки, тик, установка, `doctor`.
- `crates/vibememory-mcp` — сервер памяти и команды хоста.
- `fixtures/` — записи реальных форматов: тесты слияния, имён и памяти пишутся только через них, а не литералами в коде.
- Правила кода и проверенные факты — [CLAUDE.md](CLAUDE.md) и [docs/knowledge/](docs/knowledge/README.md).

## Проверки перед pull request

```bash
cargo fmt --check
cargo clippy --all-targets -- -D warnings
cargo clippy --workspace --all-targets --target x86_64-pc-windows-msvc -- -D warnings
cargo test
```

Windows-цель ставится один раз: `rustup target add x86_64-pc-windows-msvc`, линкер не нужен.
В `cargo test` входят гейты документации, приватности фикстур и законов слияния.

## Коммиты

Префикс в стиле conventional commits, текст по-русски: `fix(tick): …`, `feat(mcp): …`.
Одна мысль — одна строка, без точки в конце.

## Права на вклад

Отправляя pull request, вы подтверждаете, что вклад — ваш и что вы передаёте его под лицензией [AGPL-3.0](LICENSE).
Вы также разрешаете автору проекта распространять ваш вклад в составе VibeMemory и под другой лицензией: так проект может предлагать коммерческую лицензию тем, кому AGPL не подходит, и на эти деньги развиваться дальше.
