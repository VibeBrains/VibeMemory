Есть три официальных механизма, и ни один не переносит локальную сессию целиком на другой хост: Remote Control (процесс остаётся на A; B видит и рулит сессией только через браузер claude.ai/code или мобильное приложение; транскрипт хранится на серверах Anthropic только пока соединение живо; «Local process must keep running»); облачные сессии (Desktop «Continue in → Claude Code on the Web» пушит ветку и создаёт НОВУЮ облачную сессию из СВОДКИ разговора, CLI пушить не умеет вообще — «session handoff is one-way»; на B `claude --teleport <id>` тянет облачную сессию с полной историей облачной сессии и веткой как собственную копию); `/desktop` — перенос CLI→Desktop только на той же машине. Auto memory официально «machine-local… not shared across machines or cloud environments»; фоновые bash/monitor-задачи не восстанавливаются даже при локальном resume.
