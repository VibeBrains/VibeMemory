# Таблицы кабинета: без горизонтального скролла

2026-09-25, по замечанию владельца: на странице команды таблица токенов уезжала под горизонтальную прокрутку
даже на десктопе, а на телефоне от строки оставалась треть.

## Откуда скролл

`Table` пака заворачивает таблицу в `overflow-x-auto`, а каждой ячейке и заголовку ставит `whitespace-nowrap`.
Семь колонок с фразами вроде «чтение и запись, поиск по истории» в одну строку шире колонки страницы (`max-w-5xl`),
и прокрутка появляется при любой ширине окна.

## Как сделано

- Ячейки переносятся (`[overflow-wrap:anywhere]`); прокрутки у контейнера нет
- Контейнер таблицы — `@container/table`; уже `@2xl` (42rem) таблица складывается:
  строка — карточка, ячейка — строка «колонка: значение»
- Подписи колонок CSS взять из заголовка не может, поэтому ячейка получает проп `label`
  (`data-label` и `content: attr(data-label)`)
  - `XTable` берёт подпись из заголовка колонки сам, если заголовок — строка
  - Ячейка с подписью держит содержимое в одной обёртке: сложенная ячейка — сетка из двух колонок, и соседние
    `<code>` и текст иначе заняли бы по колонке
- Заголовок таблицы в сложенном виде — `sr-only`, для читалок экрана
- Плавающий заголовок (`TableHeaderSticky`) не строится, если таблица не `display: table`
- `flex` на самой `td` ломает сложение (класс `flex` спорит с `block` сложенного вида) — раскладку переносим во
  внутренний `div`

Контейнерный запрос, а не медиазапрос: таблица в узкой колонке складывается и на широком экране.

## Гейт

`team.e2e.test.ts` открывает страницу команды с выданным токеном на 375 и 1280 пикселях.
Страница не шире окна, ни один контейнер таблицы не прокручивается, таблицы сложены только на телефоне.

На первом прогоне гейт поймал не таблицу, а бейдж состояния хоста: у бейджа пака тоже `whitespace-nowrap`,
и фраза «на хосте: применяется, опубликовано меньше минуты назад» вылезала за телефон на 23 пикселя.
Бейдж теперь переносит текст и не шире родителя.
