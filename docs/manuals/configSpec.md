# Спека `~/.vibememory/config.json`

> Скопируйте этот файл целиком своей LLM и попросите собрать `config.json` для вашей машины.
> Здесь описаны **все** ключи файла. Закомментированный образец, который засевает `install`, —
> [`crates/vibememory-cli/defaults/config.sample.jsonc`](../../crates/vibememory-cli/defaults/config.sample.jsonc).

## Назначение

Файл лежит на каждой машине отдельно (не в сторе) и говорит движку, как называть стор проекта
для рабочего каталога сессии и какие каталоги оставить в покое. Пути в нём — пути **этой**
машины.

## Пример

Файл — строгий JSON: без комментариев и висячих запятых (образец рядом с движком снабжён
пояснениями — копировать без них).

```json
{
  "machineId": "mac-main",
  "remote": "ssh://git@host/vibememory/store.git",
  "roots": {
    "PROJECTS": "/Volumes/Storage/Projects",
    "HOME_PROJECTS": "/Users/me/Projects"
  },
  "desktopStore": "auto",
  "nameOverrides": {
    "/Volumes/Storage/Projects/VibeCode/VibeSweep": "VibeSweep",
    "/Volumes/Storage/Projects/VibeCode/VibeSweep/**": "VibeSweep"
  },
  "ignoreCwd": ["/"]
}
```

Минимум, на котором движок стартует, — `machineId`; всё остальное имеет умолчания.

**Незнакомый ключ — ошибка загрузки, а не «правила нет».** Опечатка (`nameOverides`) иначе
означала бы, что написанное владельцем правило молча не существует, и узнал бы он об этом,
когда сессия уехала не в тот стор. По той же причине конфиг применяется целиком или никак:
одна плохая запись отменяет весь файл, а не пропускается.

## Общие правила шаблонов (для обоих ключей)

- Шаблон — абсолютный путь в glob-синтаксисе: `/…` на macOS, `D:/…` или `//server/share/…` на
  Windows. Разделитель — **только `/`**; шаблон с `\` отвергается целиком (в glob это символ
  экранирования, и путь, скопированный из Проводника, молча никогда бы не совпал).
- Литерал совпадает **точно**: `/a/b` матчит `/a/b`, но не `/a/b/c` и не `/a/bc`. Поддерево —
  только явным `/**`: `/a/b/**` матчит `/a/b/c`, но **не** сам `/a/b`; чтобы покрыть и каталог, и
  его содержимое, нужны обе строки. `*` не пересекает `/`.
- Windows-шаблоны (с буквой диска или `//`) сравниваются без учёта регистра, POSIX — байт-в-байт.
- Сравнивается **физический** путь, как его сообщает CLI (realpath): на macOS `/tmp/x` — это
  `/private/tmp/x`, `/var/x` — `/private/var/x`; писать шаблон по выводу `pwd -P`.
- Рабочий каталог и шаблон приводятся к одной форме: разделитель `/`, NFC, `.`/`..` разрешены,
  хвостовой разделитель отброшен (`D:\Runners\one\` → `D:/Runners/one`; шаблон `/x/proj/`
  равен `/x/proj`). Корни пишутся так: `/`, `D:/`, `//server/share/` (хвостовой `/` у корня
  необязателен: `//server/share` — тот же корень).
- Каталог, в имени которого есть `[ ] { } * ?`, задаётся через класс символов: `/x/[[]work]/foo`
  для `/x/[work]/foo`, `/x/[{]a,b[}]` для `/x/{a,b}`.
- Пустой шаблон, шаблон из пробелов, относительный шаблон, шаблон-дубликат (повторный ключ в
  объекте, тот же путь в другой записи, для Windows — с точностью до регистра) и синтаксически
  битый glob (`/a/[`) — ошибка загрузки конфига (`configInvalid`); движок не работает с частично
  прочитанным конфигом.

## `nameOverrides` — объект «шаблон → имя стора»

Ручной предохранитель: применяется до git и до всех автоматических правил. Нужен для
одноимённых проектов на разных машинах, для не-git каталогов с подкаталогами, для случаев, где
автоматика отказала с ошибкой (`gitRefused`, `unrecognizedGitLayout`, `gitLayoutMismatch`).

- Значение — имя каталога под `<store>/projects/`: непустое, ≤ 255 байт, не `.`, `..`, `.git`,
  без `/ \ : * ? " < > |` и управляющих символов, без точки или пробела в конце, не
  зарезервированное имя Windows (`CON`, `AUX.js`, `COM1`…). Невалидное значение — `configInvalid`.
- Шаблон обязан содержать хотя бы один литеральный компонент: `/`, `/**`, `D:/**`,
  `//server/share/**` отвергаются — они перехватили бы все проекты машины.
- Если рабочему каталогу соответствует **больше одного** шаблона — ошибка `ambiguousOverride`
  (без правила «длиннейший побеждает»). Пишите шаблоны так, чтобы они не пересекались.
- Имя, отличающееся от уже существующего стора только регистром или формой Unicode, считается тем
  же стором: используется существующее написание.

## `ignoreCwd` — массив шаблонов

Каталоги, для которых движок не делает ничего: ни ссылки, ни стора, ни синхронизации — сессия
живёт в реальном каталоге CLI. Проверяется раньше всех остальных правил (только относительный
cwd отвергается ещё раньше); если каталог попал и в `ignoreCwd`, и в `nameOverrides`, побеждает
игнор.

- `"/"` — литерал ровно для корня (сессии раннера VibeDub). Корень файловой системы (`/`, `D:\`,
  `\\server\share`) без такого правила — ошибка `rootCwd`: стора с именем «root» не бывает.
- В ответе движка называется первый совпавший шаблон в порядке файла; порядок на результат не
  влияет.

## `machineId` — строка, обязателен

Уникальное имя этой машины (`mac-main`, `gpd-win`). Попадает в имена всего, что машина пишет в
стор: `machines/<machineId>/links.json`, heartbeat, штамп карантина. Именно поэтому конфликтов в
outbox не бывает по построению — две машины не пишут в один файл. Пустая строка и строка из
пробелов не считаются именем.

Сменить `machineId` позже — значит завести в сторе вторую машину; старые файлы останутся
лежать под прежним именем, и убрать их придётся руками.

## `remote` — строка, необязателен

Git-remote стора: `ssh://git@host/vibememory/store.git` или любая форма, которую понимает
`git remote add`. Стор — приватный репозиторий на своём хосте; зеркало в приватный GitHub делает
хост, а не движок.

Без `remote` стор живёт локально: так машина сперва мигрирует и проверяет себя, а публикует потом.
Тик до появления `remote` не делает ни fetch, ни push. Объявленный, но пустой `remote` — ошибка.

## `roots` — объект «имя корня → абсолютный путь», необязателен

Как одна и та же папка называется на разных машинах. Рабочий каталог `…/Projects/VibeCode/VibeIDE`
уезжает в стор как `{PROJECTS}/VibeCode/VibeIDE` и на второй машине превращается обратно в её
собственный путь — на Windows это `D:/Projects/VibeCode/VibeIDE`.

- Имя корня — ваше, произвольное (`PROJECTS`, `HOME_PROJECTS`, `WORK`); оно видно только в сторе.
- Путь — **абсолютный** путь этой машины; относительный отвергается: якорить он ничего не может.
- Путь приводится к канонической форме (разделитель `/`, NFC, `.`/`..` разрешены, без хвостового
  слэша) — так же, как рабочий каталог, иначе один и тот же корень дал бы два разных ответа.
- Каталог, не попавший ни под один корень, **не переводится** и потому не уезжает: корень — это
  ваше утверждение «на другой машине это та же папка», и без него переписывать путь нечестно.
- Вложенные корни допустимы: побеждает самый длинный подходящий, то есть самый конкретный.

## `desktopStore` — строка, необязателен, по умолчанию `"auto"`

Где лежат дескрипторы карточек Claude Desktop.

- `"auto"` — искать там, где их кладут установщики. На Windows раскладки Squirrel и MSIX разные,
  и на одной машине могут оказаться обе.
- Любая другая строка — путь к каталогу, если поиск ошибается.
