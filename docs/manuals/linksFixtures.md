# Как добавить кейс в `fixtures/links/`

`machines/<id>/links.json` — то, что одна машина рассказывает остальным про свои ссылки: какой
каталог `~/.claude/projects/<enc>` на какое имя стора смотрит и какой это рабочий каталог. Файл
пишет только его машина, читают все — поэтому сливать в нём нечего, но **прочитать его чужая
машина обязана точно**: по нему реконсилер заводит ссылку заранее, а фолбэк-сканы CLI и Desktop
ссылок не видят.

Тип — `crates/vibememory-core/src/links.rs`, ожидания — `fixtures/links/linksScenarios.json`,
драйвер — `crates/vibememory-core/tests/links_fixtures.rs`.

## Два раздела файла

`cases` — файл целиком и что с ним стало:

```json
{
  "id": "predicted-then-confirmed",
  "provenance": "computed",
  "note": "Догадка подтверждена transcript_path этой машины.",
  "text": "{\"version\":1,\"links\":[…]}",
  "expect": {
    "parses": true,
    "version": 1,
    "records": [{ "enc": "-a", "name": "A", "predicted": true, "confirmed": true }],
    "roundTrip": "…"
  }
}
```

- `text` — файл ровно как на диске, строкой.
- `expect.parses: false` — файл обязан быть отвергнут; прочие поля тогда не указываются.
- `expect.records[].nameParses: false` — имя не проходит `StoreName::parse`, но запись всё равно
  читается: одна битая ссылка не имеет права уронить остальные.
- `expect.roundTrip` — пин на текст, в который файл записывается обратно. Указывать там, где
  форма важна (пропуск `confirmedBy`, порядок ключей). Круг «прочитали → записали → прочитали»
  проверяется на **каждом** кейсе и без пина.

`sameName` — сравнение имён двух записей: `left`, `right`, `same`. Проверяется ещё и симметрия.

## Порядок добавления

1. Кейс в JSON, ожидание — руками из формата, не из вывода типа.
2. `cargo test --test links_fixtures` — падение до правки типа и есть смысл кейса.
3. Мутационная проверка **в копии файла, не через `git checkout`**. Годные подделки, все три
   прогнаны 2026-09-04 и все три роняют тест: снять `deny_unknown_fields` (опечатка в ключе
   перестаёт быть ошибкой), сравнить имена как написано вместо `StoreName::key()` (`VibeIDE` и
   `vibeide` перестают быть одним каталогом), писать `confirmedBy` всегда (форма файла меняется).

## Почему `provenance` здесь везде `computed`

Формат придумали мы, реального образца не существует: файл начнёт писать движок на этапе 2.
Как только `install` напишет первый настоящий `links.json`, снять с него кейс `observed` —
до тех пор ни один кейс не имеет права называться наблюдением.
