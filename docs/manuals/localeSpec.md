# Спека языкового файла кабинета

> Скопируйте этот файл целиком своей LLM вместе с `cabinet/src/modules/i18n/locales/en.json` и попросите собрать
> языковой файл кабинета VibeMemory для нужного языка. Всё, что нужно для правильного файла, — здесь.

## Где лежит и как подключается

Кабинет говорит по-русски без всяких файлов: русский — базовый язык, он в коде
(`cabinet/src/modules/i18n/ru/`). Любой другой язык — файл `cabinet/src/modules/i18n/locales/<код>.json`, где
`<код>` — код языка ISO 639-1 строчными (`en`, `de`, `uk`). Сейчас есть `en.json`.

Язык появляется в переключателе, когда его код добавлен в список `LOCALES` и файл подключён в `FILES` в
`cabinet/src/modules/i18n/index.ts` — одна строка в каждом месте. Кабинет — веб-сервис: новый язык приезжает
со следующей выкладкой.

## Формат

Один JSON-объект без вложенности: ключ — строка перевода.

```json
{
  "common.nav.teams": "Teams",
  "team.refuse.seatsTaken": "The team has {seats} seats and all are taken"
}
```

Правила:

- **Ключи — ровно те же, что в `en.json`**, ни одного лишнего. Ключ пишется как есть: плоский, через точку.
  Первая часть — область кабинета (`common`, `auth`, `team`, `admin`, `grant`, `ui`…), по ней видно, где
  строка стоит.
- **Подстановки в фигурных скобках** — `{seats}`, `{handle}`, `{slug}` — остаются в переводе теми же, с тем
  же именем. Порядок слов меняется свободно, скобка переносится туда, где ей место в языке; переименовывать
  её нельзя. Подстановка, которой нет в оригинале, останется в интерфейсе как есть, видимой скобкой.
- **Код, команды, пути и имена** не переводятся: `vibememory connect`, `~/.vibememory/tokens`, `access.json`,
  `claude-code`, `VibeMemory`, коды вида `tokenInPush`.
- **Ключа нет — показывается русская строка.** Частичный перевод годится, но гейт кабинета требует полного
  файла, поэтому в репозиторий идёт файл со всеми ключами.
- Кодировка UTF-8, отступ два пробела, в конце перевод строки.

## Тон

Кабинет пишет коротко и прямо: подпись кнопки — глагол («Сохранить»), отказ — что не так и что делать
(«Код уже использован: попросите новый»). Термины держатся одними на весь файл: «команда», «участник»,
«владелец», «токен», «ключ машины», «код-подарок». Обращение — нейтральное, без «пожалуйста».

## Проверка

```bash
cd cabinet && bunx cross-env NODE_ENV=test bun test src/modules/i18n/test/catalog.unit.test.ts
```

Гейт падает, если в файле не хватает ключа, есть лишний или подстановки не совпадают с русскими.
